### [MODERATE] E6 — Theorem 1 Proof Incomplete (k=1 Mode Not Addressed)
**Location:** Theorem 1 and proof sketch (p. 2)

The proof sketch derives the stability condition for k ≥ 2 eigenvalues of the
Laplacian. The k=1 eigenvalue (λ₁=0, uniform mode) corresponds to a uniform
price shift and must also be handled.

The update Δp(t+1) = (I − λᾱW + λβ̄M)Δp(t) + η applied to the uniform mode
(all prices shift by the same amount) gives:
  Δp_uniform(t+1) = (1 − λᾱ(1−λ₁^L) − λβ̄ν₁)Δp_uniform(t)
                   = (1 − 0 − λβ̄ν₁)Δp_uniform(t)

Whether this is stable depends on ν₁ (the momentum operator eigenvalue for the
uniform mode). The paper never establishes this is in (0,2).

**Fix:** Either complete the proof for k=1 explicitly, or add a remark showing
why the uniform mode is stable by the fundamentalist restoring force (which the
proof sketch omits for k=1).

**STATUS: PATCH WRITTEN — see PAPER_PATCHES.md PATCH E6**
Argument: ν₁ ∈ (0,1) because M is a contraction on bounded price histories;
with λβ̄ = 0.008, the product λβ̄·ν₁ ∈ (0, 0.0016) ⊂ (0,2) → stable.

### [MODERATE] E7 — c(λ₂) Can Exceed 1 (Undefined Behaviour)
**Location:** Eq. (4), Section 2.2

The blending coefficient c(λ₂) = log(1+λ₂)/log2.
- At λ₂ = 0: c = 0 ✓
- At λ₂ = 1: c = 1 ✓
- At λ₂ > 1: **c > 1**, making the global-price weight (1−c) negative.

Dense random graphs can have λ₂ > 1. My simulation confirms λ₂ ≈ 0.656 at κh=0
for n=80, dmax=12 — close to the boundary. With larger n or higher dmax, λ₂ > 1
is likely, producing a weight flip in Eq. (4).

**Fix:** Either restrict c = min(c(λ₂), 1), or derive the parameter ranges
under which λ₂ ≤ 1 is guaranteed, and state this as a model constraint.

**STATUS: PATCH WRITTEN — see PAPER_PATCHES.md PATCH E7**
Clamp c = min(log(1+λ₂)/log2, 1.0) already implemented in cme_canonical.py
line 217 (np.clip). Paper text must be updated to reflect this clamp.

## E3 (continued) — TMFI 15× Discrepancy Investigation (tmfi_window_fix.py)

**Status:** INVESTIGATED — no clean fix found; discrepancy confirmed as model-specification gap

**Problem:** The canonical simulation gives TMFI ratio κh=0/κh=6 ≈ 15.5× but
the paper claims 1.30×. Root cause: instantaneous community means of neighbourhood-blended
p_obs are highly noisy at κh=0 (c_lam≈0.92 amplifies neighbour noise).

**Approaches tested (tmfi_window_fix.py, 7 κh values × 20 seeds):**

| Method        | TMFI(κh=0) | TMFI(κh=6) | Ratio   | Direction OK? | Monotonic? |
|---------------|------------|------------|---------|---------------|------------|
| Instantaneous | 0.00039    | 0.00003    | 15.50×  | ✓ (falls)     | ✓          |
| Window=10     | 0.00013    | 0.00001    | 15.47×  | ✓             | ✓          |
| Window=20     | 0.00009    | 0.00001    | 15.80×  | ✓             | ✓          |
| Window=50     | 0.00006    | 0.00000    | 15.75×  | ✓             | ✓          |
| MA-based      | 0.01591    | 0.01537    | 1.035×  | ~✓ (spurious) | ✗ (peaks κh=5) |

**Key finding:** Rolling-window smoothing does NOT help — the ratio stays ~15× regardless
of window size (10, 20, 50 steps). The noise is structural: at κh=0 the c_lam≈0.92
blending coefficient means 92% of each agent's p_obs is the neighbourhood average, and
at κh=0 the neighbourhood spans all τ-types (random mixing) → large community spread.
Smoothing over time reduces the absolute values but preserves the 15× ratio.

**MA-based approach:** Community means of per-agent τ_i-period MA of global price give
ratio=1.035×, which numerically is close to 1.30×. However this approach has a
NON-MONOTONIC κh profile (TMFI peaks at κh=5, not κh=0), meaning the correct direction
(TMFI falls with κh) is only achieved by coincidence. This is NOT a valid fix.
cme_canonical.py was NOT updated.

**Root cause conclusion:** The paper's TMFI computation is underspecified. To reproduce
1.30×, the paper likely uses a fundamentally different TMFI path: possibly (a) community
means of the blended price WITHOUT noise (noiseless observation path), or (b) TMFI
defined over the inter-community price *level* dispersion rather than fractional noise.
The exact definition requires the authors' original code.

**Impact on asymmetry:** The asymmetry gap (normalised σ drop 0.492 vs normalised TMFI
drop 0.871, reversed from paper's 0.948 vs 0.558) persists and cannot be resolved without
the correct TMFI formula. This is a fundamental reproducibility gap in the paper.
